SynDiary ships regularly through its beta channels: [Google Play beta](https://play.google.com/apps/testing/com.syndiary.coreapp) and [TestFlight](https://testflight.apple.com/join/mf47MN6d). Each store listing carries its own release notes for that update. This page will collect the highlights across releases, newest first, as the beta progresses.

## Current beta

The current beta centers on the core experience: a timeline built from entries you create yourself, plus data you choose to bring in from calendars and archives. It includes:

- A timeline of entries, including basic, event, person, organization, media, audio, social media, and place entries
- Bringing in data from device calendars and calendar feeds, and preparing Instagram/Facebook archives for import
- On-device AI, with an optional cloud AI path using your own API key
- Reports built from your entries, viewable as stat cards and charts

:::note[Beta]
SynDiary is in beta, so details may shift between releases.
:::
